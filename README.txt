سيول لقطع الغيار الكورية — SEOUL Auto Parts
============================================

محتويات المجلد
--------------
index.html                          الموقع (يقرأ الصور من مجلد img)
img/                                صور السيارات والقطع + علامة الشعار
logo/                               ملفات الشعار (SVG بكل الأفكار + PNG شفاف)
seoul-auto-parts-single-file.html   نفس الموقع في ملف واحد، الصور مضمّنة داخله

طريقة الرفع على الاستضافة
-------------------------
ارفع index.html ومجلد img كما هما (نفس الترتيب) إلى المجلد الرئيسي في الاستضافة
(مثل public_html). أو ارفع الملف الواحد seoul-auto-parts-single-file.html فقط.

قبل النشر — عدّل هذه القيم داخل index.html
-------------------------------------------
- رقم الواتساب: ابحث عن 966500000000
- أرقام الهاتف: 920000000 و 0112345678 و 0122345678 و 0132345678 و 0500000000
- القطع والأسعار: ابدأ من السطر  const RAW=[
  كل سطر = قطعة: الاسم، رقم القطعة، الماركة، الموديلات، السنوات، القسم،
  أصلي (oem) أو تجاري (aft)، السعر، السعر القديم، الكمية
- السجل التجاري والرقم الضريبي في الفوتر (قيم تجريبية)
- الشريط الأصفر أعلى الصفحة "نموذج تصميم ثانٍ — موقع تجريبي": احذفه
